# Конференция: система + микрофон

Сценарий созвона: звук собеседников идёт через системный вывод (loopback), ваш голос — через микрофон. Оба потока пишутся вместе.

## Файлы

| Файл | Роль |
| --- | --- |
| `conference_recorder_ext.py` | Ядро (callback + очереди, CPU/WASAPI) |
| `conference_grab_ext.py` | GUI |

`conference_recorder_ext.py` — не отдельный launcher, а движок. Запуск — через GUI:

```bash
python conference_grab_ext.py
```

## Режимы записи

- **continuous** — один большой файл
- **segments** — нарезка в папку по N секунд

## Раскладка каналов

- **stereo** — L = система, R = микрофон (удобно для постобработки)
- **mix** — моно-микс

## Пути в GUI

- **Папка** — каталог сохранения
- **Файл** — базовое имя, например `conference.wav`
- **Полный путь** — preview

При **Старт** в continuous к имени добавляется метка `YYYYMMDD-HH-MM-SS` перед расширением. Смена формата меняет расширение поля «Файл».

## Советы

- Loopback = устройство, куда играет звук созвона.
- Микрофон лучше брать WASAPI-вариант того же гарнитура (часто совпадает sample rate с loopback, ~48 kHz).
- Для длинных сессий предпочтительнее `wav` continuous или segments.
